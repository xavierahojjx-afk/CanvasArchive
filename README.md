# GSB Canvas Archive

Python CLI that archives Stanford GSB Canvas course materials to Google Drive.

See `../PROJECT.md` for full spec. Detailed setup and CLI reference will be
added once the implementation is verified end-to-end.

## Quick start (placeholder)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
# edit .env to add your CANVAS_TOKEN
python -m canvas_export discover
```
